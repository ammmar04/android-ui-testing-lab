# Android UI Testing Lab

An Android/Java coursework project that uses Espresso instrumentation tests to exercise a simple city-list interface.

## What it covers

- Adding and clearing cities in the main activity.
- Navigating to a second activity and checking displayed city details.
- UI assertions and simulated user actions in `app/src/androidTest/`.

## Run the tests

Open the project in Android Studio, start an emulator or connect an Android device, and run the instrumentation tests under `app/src/androidTest/`. The project targets Android SDK 34.

This is a focused testing lab rather than a production Android app.
